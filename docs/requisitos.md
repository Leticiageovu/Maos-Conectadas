# Requisitos

## Requisitos funcionais

- RF01: cadastrar produtos com nome, descrição, categoria, preço, foto opcional e quantidade.
- RF02: consultar o catálogo completo.
- RF03: pesquisar produtos pelo nome.
- RF04: atualizar os dados e a quantidade de um produto.
- RF05: excluir produtos.

## Requisitos não funcionais

- RNF01: interface responsiva.
- RNF02: API REST com validação de entrada.
- RNF03: persistência compatível com PostgreSQL.
- RNF04: testes automatizados para a lógica principal.
- RNF05: build e testes executados por integração contínua.
